# project-6

Today, I am using Monte Carlo Simulation to understand the possible paths of an asset price. The Monte Carlo simulation uses the Geometric Brownian Model (GBM), which is a stochastic process commonly used to model asset prices. The mathematical equation that describes GBM is: dSt​= μStdt + σSt​dWt. 

Where St is the asset price at time t; μ is the expected return (drift), σ is the volatility, and dWt is the random component.
